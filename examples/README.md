# Benchmark image

`bench_photo.jpg` — одна фотография овощей, вырезанная из визуализации, сохранённой в исходном исследовательском ноутбуке. Исходный датасет: Kaggle `preethi866/vegetable-dataset`, версия 1, лицензия данных Apache 2.0. Используется **только для измерения CPU-времени и smoke-тестов**, не как независимая оценка точности. Исходный кадр не является новой магазинной фотографией.
